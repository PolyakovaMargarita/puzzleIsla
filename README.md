# Что заливать на GitHub Pages

Всё лежит прямо в этой папке `docs/`.

## Репозиторий `puzzleIsla`

Скопируй в **корень** репо:

- `index.html`
- `privacy.html`
- `support.html`

Pages: ветка `main`, папка `/`.

Ссылки:
- https://polyakovamargarita.github.io/puzzleIsla/privacy.html
- https://polyakovamargarita.github.io/puzzleIsla/support.html

## Репозиторий `polyakovamargarita.github.io` (домен + AdMob)

Скопируй в **корень** репо:

- `app-ads.txt`
- `site-home.html` → сохрани как **`index.html`** (иначе главная будет 404)

В AdMob / Play поле «сайт»: `https://polyakovamargarita.github.io`  
Проверка:
- https://polyakovamargarita.github.io/ (должна открыться страница, не Not Found)
- https://polyakovamargarita.github.io/app-ads.txt

`app-ads.txt` в `puzzleIsla` не клади — Google читает его только с домена.
